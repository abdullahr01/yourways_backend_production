1. Project Overview
The Cargo Logistics Platform is a complete digital solution designed for cargo booking, goods transportation, live tracking, and logistics management.
The system consists of:
Customer Mobile Application 
Driver Mobile Application 
Customer Website 
Admin Panel 
Backend Infrastructure 
The platform enables users to book drivers for transporting goods from one location to another while providing real-time tracking, quotation generation, notifications, and centralized administrative control.
The project is designed to simplify logistics operations, improve customer experience, and automate the cargo booking workflow.
2. Project Objectives
The main objectives of the project are:
Provide an easy cargo booking system 
Automate quotation generation 
Enable real-time order tracking 
Improve logistics management 
Centralize booking and driver management 
Provide live order status updates 
Offer seamless mobile and web experience 
Enable targeted promotional notifications 
Create scalable infrastructure for future expansion

6. Complete Workflow
6.1 Customer Registration/Login
User enters phone number 
OTP is sent using Firebase Authentication 
User verifies OTP 
Account is created/login successful 
6.2 Cargo Booking Flow
Step 1 — Select Goods
User selects:
Categories 
Subcategories 
Quantity 
Weight 
The system allows multiple item selections.
Step 2 — Enter Locations
User enters:
Pickup location 
Dropoff location 
Google Places API will provide:
Location suggestions 
Address autocomplete 
Step 3 — Get Quotation
The backend calculates quotation using:
Distance 
Weight 
Quantity 
Traffic conditions 
Service charges 
The system returns:
Estimated cost 
Estimated delivery time 
Taxes and additional charges 
Step 4 — Confirm Booking
User reviews quotation and confirms booking.
Booking status:
Pending
6.3 Admin Workflow
Admin receives booking request 
Admin reviews booking details 
Admin assigns driver 
Booking status changes to: 
Confirmed
6.4 Driver Workflow
Step 1 — Driver Login
Driver logs in using OTP verification.
Step 2 — View Assigned Orders
Driver views:
Today's bookings 
Pickup/dropoff details 
Customer information 
Step 3 — Pickup Process
Driver starts journey.
Booking status:
Out for Pickup
At pickup:
Driver uploads goods images 
]Customer provides signature 
Booking status:
Pickup Completed
Step 4 — Delivery Process
Driver starts delivery.
Booking status:
Out for Dropoff
At dropoff:
Driver uploads delivery images 
Customer provides signature 
Booking status:
Order Completed
6.5 Notifications Workflow
The customer receives push notifications for:
Booking confirmation 
Driver assignment 
Pickup started 
Pickup completed 
Delivery started 
Order completed 
Notifications are sent using Firebase Cloud Messaging (FCM).
6.6 Live Tracking Workflow
The system tracks:
Driver location 
Delivery route 
Current order status 
Users can track orders live on Google Maps.
Admin can also monitor all active deliveries.
6.7 Smart Promotion Feature
When a driver enters another city:
System detects city location 
Previous customers in that city are identified 
Promotional notifications are sent 
Example:
“A driver is available in your area today. Book now and get special discount.”
7. Booking Status Flow
Pending↓Confirmed↓Out for Pickup↓Pickup Completed↓Out for Dropoff↓Order Completed
